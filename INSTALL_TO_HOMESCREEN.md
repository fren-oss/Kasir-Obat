# 📱 Cara Install Kasir Obat ke Home Screen

Aplikasi Kasir Obat bisa diinstall ke home screen HP Anda seperti aplikasi biasa, **tanpa perlu Play Store atau App Store!**

---

## 📱 Android

### Via Chrome:
1. Buka aplikasi di **Google Chrome**
2. Tap menu **⋮** (3 titik) di pojok kanan atas
3. Pilih **"Install app"** atau **"Add to Home Screen"**
4. Tap **"Install"** atau **"Add"**
5. ✅ Selesai! Icon muncul di home screen

### Via Browser Lain:
1. Buka aplikasi di browser
2. Tap menu → **"Add to Home Screen"**
3. Konfirmasi

**Screenshot:** Icon "Kasir Obat" akan muncul di home screen seperti app biasa

---

## 🍎 iPhone / iPad (iOS)

### Via Safari (WAJIB!):
1. Buka aplikasi di **Safari** (harus Safari, bukan Chrome!)
2. Tap tombol **Share** 📤 (kotak dengan panah ke atas) di bawah
3. Scroll ke bawah
4. Pilih **"Add to Home Screen"** ➕
5. Edit nama jika perlu (default: "Kasir Obat")
6. Tap **"Add"** di pojok kanan atas
7. ✅ Selesai! Icon muncul di home screen

**Tips iOS:**
- Harus buka di Safari (bukan Chrome/Firefox)
- Kalau tidak ada opsi "Add to Home Screen", scroll terus ke bawah
- Pastikan tidak dalam mode Private/Incognito

---

## 💻 Desktop (Windows/Mac/Linux)

### Via Chrome/Edge:
1. Buka aplikasi di browser
2. Lihat icon **Install** ⊕ atau **+** di address bar (pojok kanan)
3. Klik icon tersebut
4. Klik **"Install"**
5. ✅ App akan terbuka di window terpisah

### Manual:
1. Klik menu **⋮** (3 titik)
2. Pilih **"Install [App Name]"** atau **"Create shortcut"**
3. Centang **"Open as window"**
4. Klik **"Install"**

---

## ✨ Keuntungan Install ke Home Screen

✅ **Akses cepat**: Langsung dari home screen, tidak perlu buka browser
✅ **Fullscreen**: Seperti aplikasi native, tanpa address bar browser
✅ **Offline**: Tetap bisa dibuka walau internet lambat/mati (cached)
✅ **Update otomatis**: Tidak perlu download update manual
✅ **Hemat space**: Lebih kecil dari app native (hanya cache)
✅ **No install size**: Tidak ada "installing" seperti app store

---

## 🎯 Cara Buka Setelah Install

### Mobile:
Tap icon **"Kasir Obat"** di home screen → Langsung buka fullscreen!

### Desktop:
Klik shortcut di desktop/start menu → Buka di window terpisah

---

## ❓ Troubleshooting

### Android: Tidak ada opsi "Install app"
- ✅ Pastikan buka di Chrome (versi terbaru)
- ✅ Refresh halaman (Ctrl+R atau pull down)
- ✅ Gunakan alternatif: Menu → "Add to Home Screen"

### iOS: Tidak ada "Add to Home Screen"
- ✅ **HARUS buka di Safari** (bukan Chrome/Firefox!)
- ✅ Keluar dari mode Private/Incognito
- ✅ Update Safari ke versi terbaru
- ✅ Scroll terus ke bawah di menu Share

### Desktop: Icon install tidak muncul
- ✅ Refresh halaman (Ctrl+Shift+R untuk hard refresh)
- ✅ Gunakan menu: Settings → More tools → Create shortcut
- ✅ Update browser ke versi terbaru

### Setelah install, app tidak buka
- ✅ Hapus dari home screen dan install ulang
- ✅ Clear browser cache
- ✅ Pastikan koneksi internet aktif (untuk load pertama kali)

---

## 🗑️ Cara Uninstall

### Android:
- Tekan dan tahan icon → **Uninstall** atau **Remove**

### iOS:
- Tekan dan tahan icon → **Remove App** → **Delete App**

### Desktop:
- Right-click icon → **Uninstall** atau **Remove**
- Atau via browser settings → Installed apps → Uninstall

---

## 🔄 Update Aplikasi

**Tidak perlu uninstall dan install ulang!**

Aplikasi akan **otomatis update** saat:
- Buka aplikasi dengan koneksi internet
- Developer push update baru
- Refresh halaman (pull down atau Ctrl+R)

Tidak ada notifikasi update seperti Play Store, langsung terupdate!

---

## 📞 Butuh Bantuan?

Jika ada masalah instalasi:
1. Screenshot error yang muncul
2. Sebutkan device (Android/iOS) dan browser
3. Hubungi support/developer

## 🎓 Edukasi User

**"Aplikasi web modern tidak perlu download dari Play Store!"**

PWA (Progressive Web App) adalah teknologi yang memungkinkan website berfungsi seperti aplikasi native:
- Install langsung dari browser
- Bisa offline
- Notifikasi push (tergantung fitur)
- Update otomatis tanpa approval App Store

Perusahaan besar yang pakai PWA:
- Twitter Lite
- Starbucks
- Uber
- Pinterest
- Spotify Web Player

**Kasir Obat menggunakan teknologi yang sama!** 🚀
